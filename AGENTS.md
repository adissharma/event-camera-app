# Mobile web glass

Mobile web uses the tinted blur (`EventGlass`) on the event card. Do not add Liquid Glass or bent-glass effects to mobile web unless the owner explicitly asks for it in that request. The check lives in `src/components/ui/cover-glass.web.tsx`.
